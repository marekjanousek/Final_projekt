Cíl projektu

Tento web je vytvořen jako komplexní prezentace na téma Assassin's Creed III s použitím čistých webových technologií bez externích frameworků.

Technické specifikace

  • HTML5 pro strukturu stránek
  • CSS3 se základem Grid a moderními styly
  • Vanilla JavaScript pro jednoduché efekty
  • Žádné frameworky jako React, Vue, Angular, Bootstrap nebo Tailwind

Výkon

V projektu jsem minimalizoval počet HTTP požadavků tím, že používám jednu hlavní CSS sadu. Obrázky jsou načítány s atributem loading="lazy" a kód je organizován tak, aby byl co nejpřehlednější.

SEO

Stránky mají validní HTML, meta description, Open Graph a Twitter Card meta tagy pro lepší sdílení. K dispozici je také sitemap.xml a robots.txt.

Přístupnost

Web používá sémantické elementy jako header, nav, main a section. Navigace má atributy ARIA a obrázky obsahují alt texty.

Sociální sítě

Open Graph a Twitter meta tagy zajišťují správný náhled při sdílení odkazů na sociálních sítích.

UI/UX

Stránky jsou responzivní, zobrazení je optimalizované pro mobilní zařízení a struktura umožňuje snadnou orientaci uživatele.

AI integrace

Při ladění projektu byly použity AI nástroje pro analýzu kódu, kontrolu cesty k souborům a návrh dokumentace. To pomohlo rychle odhalit chyby a doplnit potřebné informace.
